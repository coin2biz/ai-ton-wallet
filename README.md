### 🚀 What is this?
A real Web3 wallet dApp that sends **actual TON coins** on TON blockchain. Not demo, not testnet - Mainnet real transactions verifiable on Tonscan.

### ✨ Features
- 🔌 **TON Connect UI** - Connect Tonkeeper / MyTonWallet
- 💰 **Real Balance** - Fetches live balance via TON Center API
- ⚡ **Real Send** - Sends real TON with Tonkeeper approval
- 🔍 **Tonscan Integration** - View transaction on blockchain explorer
- 📱 **Mobile First** - Built for mobile, single wallet UI
